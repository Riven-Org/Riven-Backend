# S09.4 · Interactive graph explorer

- **Epic:** E09 · Causal Graph 2.0 (Phase 3: Core Features — MVP Hardening)
- **Priority:** P1 · **Effort:** 5 story points
- **Depends on:** S09.2, S10.1
- **Repos:** backend, frontend
- **Suggested tech / approach:** React + Cytoscape.js (or Sigma.js for large graphs)

## Description

Expand-on-click explorer with filters, path finding ('how is REQ-12 connected to BUG-45?') and large-graph performance.

## Acceptance criteria (story)

- [ ] Filter by node/edge type and date
- [ ] Shortest path between two nodes
- [ ] Smooth interaction at 2k visible nodes

## Epic context

Evolve the modest MVP graph into a versioned, provenance-rich, time-aware knowledge graph with automated extraction and an interactive explorer.

Epic acceptance criteria:

- Graph schema versioned with migrations
- Edges auto-created for ≥ 95% of changes/tests/bugs
