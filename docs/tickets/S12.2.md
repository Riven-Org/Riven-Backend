# S12.2 · Change risk scoring

- **Epic:** E12 · AI-Powered Verification Intelligence (Phase 4: Advanced Features)
- **Priority:** P1 · **Effort:** 5 story points
- **Depends on:** S09.2, S14.2
- **Repos:** backend
- **Suggested tech / approach:** Gradient boosting (LightGBM) or heuristic v1

## Description

Score each change by module bug density, churn, lock proximity, producer track record and size; drive verification depth.

## Acceptance criteria (story)

- [ ] Score 0–100 with explanation factors
- [ ] High-risk changes trigger extended verification profile
- [ ] Model evaluated monthly (AUC)
