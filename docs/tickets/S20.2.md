# S20.2 · Customer secrets & log redaction

- **Epic:** E20 · Platform Security & Compliance (Phase 7: Security & Compliance)
- **Priority:** P0 · **Effort:** 5 story points
- **Depends on:** S02.2, S11.3
- **Repos:** backend
- **Suggested tech / approach:** Envelope encryption (KMS), log scrubber

## Description

Securely inject repo secrets needed for tests; never persist or log them; redact in logs/reports/LLM calls.

## Acceptance criteria (story)

- [ ] Secrets encrypted with per-tenant keys
- [ ] Secret values redacted from all stored logs
- [ ] Secrets never available to untrusted forks' PRs
