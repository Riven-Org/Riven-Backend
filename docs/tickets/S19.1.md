# S19.1 · Autoscaled Kubernetes sandbox fleet

- **Epic:** E19 · Performance & Throughput (Phase 6: Performance & Scalability)
- **Priority:** P1 · **Effort:** 8 story points
- **Depends on:** S06.5, S02.4
- **Repos:** backend
- **Suggested tech / approach:** Kubernetes Jobs, KEDA, Karpenter

## Description

Run sandboxes as K8s Jobs on an isolated node pool, autoscaled on queue depth, with warm pools.

## Acceptance criteria (story)

- [ ] Scale 0→N on queue depth
- [ ] Warm pool reduces start latency to < 10s
- [ ] Per-tenant concurrency limits
