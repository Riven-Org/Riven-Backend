# S20.1 · Sandbox isolation hardening

- **Epic:** E20 · Platform Security & Compliance (Phase 7: Security & Compliance)
- **Priority:** P0 · **Effort:** 8 story points
- **Depends on:** S06.3, S19.1
- **Repos:** backend
- **Suggested tech / approach:** gVisor RuntimeClass, Pod Security Admission 'restricted'

## Description

Kernel-level isolation for untrusted code: gVisor/Kata runtime, seccomp, no privilege, read-only rootfs, no cloud metadata access, dedicated nodes.

## Acceptance criteria (story)

- [ ] Sandboxes run under gVisor (runsc) or Kata
- [ ] Metadata endpoint unreachable from sandbox
- [ ] Escape test suite in CI
