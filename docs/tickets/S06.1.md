# S06.1 · Reproducible environment builder

- **Epic:** E06 · Sandbox Platform 2.0 (Phase 3: Core Features — MVP Hardening)
- **Priority:** P0 · **Effort:** 8 story points
- **Depends on:** S01.2
- **Repos:** backend
- **Suggested tech / approach:** BuildKit, registry cache, buildpacks-style detection

## Description

Detect language/framework, honor riven.yaml, build cached images per repo+lockfile hash.

## Acceptance criteria (story)

- [ ] Stack auto-detected for Python, Node, Java, Go
- [ ] Rebuild skipped when lockfile unchanged
- [ ] Build logs visible in run detail

- **Repo:** backend
- **Size:** M (S ≤ 1 day, M 2–3 days, L 4–5 days)

### S06.1.2 · riven.yaml schema (setup, test cmd, services, env)

- **Repo:** backend

## Epic context

Make the sandbox reproducible for real-world stacks: auto environment build, service dependencies, resource and network limits, artifact capture and guaranteed cleanup.

Epic acceptance criteria:

- Demo + 3 external open-source repos (Python, Node, Java) run without manual setup beyond riven.yaml
- No sandbox outlives its TTL
- Egress denied by default
