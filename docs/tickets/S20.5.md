# S20.5 · Verification attestation & tamper-evident audit

- **Epic:** E20 · Platform Security & Compliance (Phase 7: Security & Compliance)
- **Priority:** P1 · **Effort:** 5 story points
- **Depends on:** S07.6, S04.4
- **Repos:** backend
- **Suggested tech / approach:** Sigstore (cosign), in-toto attestations

## Description

Vision 'full attestation': sign every verdict (what was verified, by whom, with which image/policy), and hash-chain the audit log.

## Acceptance criteria (story)

- [ ] Each verdict produces a signed in-toto/SLSA-style attestation
- [ ] Attestations verifiable with public CLI
- [ ] Audit log hash chain verified nightly
