# S20.3 · Encryption & data protection

- **Epic:** E20 · Platform Security & Compliance (Phase 7: Security & Compliance)
- **Priority:** P0 · **Effort:** 3 story points
- **Depends on:** S02.4
- **Repos:** backend
- **Suggested tech / approach:** AWS KMS, cert-manager, service mesh (optional Linkerd)

## Description

TLS everywhere, encryption at rest (DB, S3, backups), key rotation.

## Acceptance criteria (story)

- [ ] TLS 1.2+ enforced incl. internal traffic (mTLS optional)
- [ ] All stores encrypted at rest with KMS
- [ ] Key rotation documented and tested
