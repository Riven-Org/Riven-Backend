# S12.1 · Specification-to-test generation

- **Epic:** E12 · AI-Powered Verification Intelligence (Phase 4: Advanced Features)
- **Priority:** P1 · **Effort:** 8 story points
- **Depends on:** S05.4, S07.1
- **Repos:** backend
- **Suggested tech / approach:** Claude API, sandbox validation

## Description

Generate executable tests from requirement nodes; human approval; tests become Riven-owned independent checks.

## Acceptance criteria (story)

- [ ] Generated tests linked to requirement in graph
- [ ] Tests require approval before affecting verdicts
- [ ] Generated tests stored separately from producer tests

## Epic context

Go beyond running existing tests: generate tests from specs, score change risk, automate root-cause bisection, answer natural-language questions and add property-based/fuzz verification.

Epic acceptance criteria:

- Spec-derived tests catch ≥ 30% of seeded spec violations missed by existing tests (benchmark)
- Risk score correlates with actual failures (AUC ≥ 0.7)
- NL queries answered with citations
