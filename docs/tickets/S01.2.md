# S01.2 · Durable workflow orchestration for the verification pipeline

- **Epic:** E01 · Production Architecture & Service Foundation (Phase 1: Foundation & Infrastructure)
- **Priority:** P0 · **Effort:** 8 story points
- **Depends on:** S01.1
- **Repos:** backend
- **Suggested tech / approach:** Temporal (self-hosted or Temporal Cloud), temporalio Python SDK

## Description

Model Capture → Analyze → Sandbox → Verify → Detect → Memory → Graph as a durable workflow with retries, timeouts and idempotency.

## Acceptance criteria (story)

- [ ] Each pipeline stage is a retriable activity with explicit timeout
- [ ] Killing a worker mid-run resumes from the last completed stage
- [ ] Re-delivered webhook for the same commit does not create a duplicate run
