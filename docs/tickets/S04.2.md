# S04.2 · Outbound webhooks

- **Epic:** E04 · Public API & Core Platform Services (Phase 2: Auth & Core Platform)
- **Priority:** P1 · **Effort:** 5 story points
- **Depends on:** S01.3, S04.1
- **Repos:** backend, frontend
- **Suggested tech / approach:** Event consumer + delivery worker

## Description

Customers subscribe to domain events with HMAC-signed, retried deliveries.

## Acceptance criteria (story)

- [ ] Signed payloads with timestamp
- [ ] Exponential retry up to 24h; delivery log visible
- [ ] Endpoint auto-disabled after repeated failures, with notification
